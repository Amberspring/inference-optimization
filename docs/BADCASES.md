# 实际故障与演练

| 场景 | 发现/注入方式 | 修复与检查 |
|---|---|---|
| 故障后立即重试仍返回旧降级答案 | 并发合并完成任务短暂残留，初始回归测试失败 | 新请求移除已完成任务；回调仅清理对应任务，避免清掉新的任务 |
| 第一次金融请求超时 | RAG 冷加载大于网关截止时间 | RAG 在启动时加载，HTTP 链路复测 |
| 模拟 OOM | 抛出模拟 RuntimeError，没有真实 GPU OOM | 安全降级不写缓存，解除故障后恢复 |
| 模拟超时 | 上游等待超过 deadline | 超时包括等待并发槽，安全转人工 |
| 模拟后端断开 | httpx ConnectError | 降级并在连续故障后熔断 |
| 模型输出截断 | mock HTTP 返回 finish_reason=length | 视为失败并调用配置的小模型兜底 |
| 生成引用错误 | mock HTTP 返回不在证据集的 [99] | 返回真实摘录，避免伪引用 |
| 并发增长后本机 P95 上升 | 真实 loopback HTTP 压测 | 保留曲线数据；CPU mock 和 Windows 客户端瓶颈不能外推到 GPU |

故障注入只作用于测试中的 Engine 实例，服务没有公开故障开关。Redis 停服、真实 GPU OOM、显卡利用率及恢复时间尚未实测。
